# Smoke test

A document small enough to read in one screen and wide enough to prove the parts a
release depends on: a heading, a table, a list, a link, and a directive.

:::note
The build's own smoke test converts this file and checks what came back. If a
construct is added here, the checks are what decide whether it still arrives.
:::

## Text

A paragraph with *emphasis*, **strong** and `code`, so a run that loses its
formatting is visible in the output rather than only in the markup.
